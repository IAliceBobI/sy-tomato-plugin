划选任意两个词，一条曲线就把它们连起来——这是思维导线的**划词连线**：文章里的呼应、伏笔、比喻、对比，划两下就显形，特别适合作文和长文的结构分析。思维导线同时还能把文档中的**引用**渲染为块间连线，让纯文本大纲也能呈现网络状脑图。在插件设置中开启「思维导线」总开关后可用。

## 快速上手：划两个词，连一条线

功能默认关闭，首次使用请先按下方「使用前提」开启。

1. 划选第一个词，划词工具条（划词菜单）弹出，点击上面的**连线按钮**（两点一线图标）；也可以按 `⌥⌘Y`，或右键菜单选「关联起点」。
2. 划选第二个词，工具条按钮变成 `连到：「××」`，点击它——两个词之间画出一条曲线，词底带端点圆点，两端闪高亮。

[图片]

[视频]

两步之间顶部有状态芯片 `已选「××」 · 请选终点` 提示进度，按 `Esc` 或点芯片上的 × 可取消。

画好的线是活的：

- 悬停线体（触屏长按），中点浮出迷你条：给线选关系色（关联 / 首尾呼应 / 伏笔 / 比喻 / 对比 / 因果）或删除该线；
- 点线体或锚词：跳到另一端并闪高亮；
- 一端滚出视口时，可见端锚词旁出现「去向」小条，点击平滑跳到另一端；
- 锚词常态带关系色淡背景；跨行时若对端在上方，出线改从词的顶缘引出、上方以悬线加圆点标注，避免绕大弯。

关系配色为 Pro 样式档：未激活时全部线为单色，画线、跳转、删除等功能不受影响。

## 使用前提：三层开关

词级连线需要同时满足三层条件：

1. 插件设置中开启「思维导线」总开关；
2. 同一分区开启「词级导线（划词连线）」；
3. 为目标文档启用思维导线：右键菜单「启用或禁用文档思维导线」（⇧⌘Z），或全局开启（⌥⌘↩）。

只看块级自动线（引用连线）时，第 2 层无需开启。

## 划词连线的细节

- **三个入口**：划词工具条连线按钮、快捷键 `⌥⌘Y`、右键菜单，两步流的每一步都可任选入口；
- **同词与跨文档**：起点终点是同一个词会提示；词级导线只能连接同一文档内的词（块级引用线可跨文档，见下节）；
- **起点跨刷新不丢**：起点划好后刷新页面或重开文档，标记并不丢失——点击任意单端圆点或锚词，状态芯片即重现，任一入口续连成线；
- `Esc` 或点芯片上的 ×：删除这个未完成的标记；
- 已有起点时点击另一个单端锚词：换起点（替换语义）；
- `Esc` 的让位顺序：菜单、联想层等浮层开着时，第一次 Esc 归浮层，第二次才取消芯片。

## 块级自动线：引用渲染为连线

- 文档中的引用自动渲染为块间连线；配合「双向互链」创建的轻量链接同样成线，且内容剪切粘贴后连线依然保持；
- 「只关联星号 * 引用」开启后，仅星号引用成线；
- 词级线与块级线可同屏共存：词级为曲线 + 端点圆点 + 语义色，块级保持直线；
- 可在设置中调整线型（虚线 / 流动 / 实线 [VIP]）、线条宽度。

## 背景：基于文本的网络脑图

传统脑图通常是**树形结构**：从任何节点回溯到根节点只有唯一路径，清晰、层级分明。现代脑图工具的趋势则是允许**在任意两个节点之间建立关联**，把树变成网络图，更贴近知识点的真实联系。

大纲（列表）本身也是树形结构，可以相对容易地转换成树形脑图：

## 进阶：配合双向互链使用轻量链接

可配合[🍅双向互链](https://my.feishu.cn/docx/DmGUdmtacol9ANxy0Encl1ownfP)中的用法1，一起使用。

可获得的好处是，不依赖于重型的引用，而是依赖轻量级的链接。

以及无视块 ID 的变化——把带链接的内容剪切后粘贴到别处，连线依然保持完整。

双向互链用法 1（创建互相跳转的链接）：

使用 `Alt+F1` 选择第一个块，在第二个块处使用 `Alt+F2`，这样就创建好了两个互相跳转的链接。

`Alt+Shift+F1` 可以修复双向链接。比如把内容剪切后再粘贴导致块 ID 发生变化，可以用 `Alt+Shift+F1` 修复。
