[番茄工具箱-帮助](https://my.feishu.cn/docx/IWPcd438yoL3C6xHC0xcOXDKnmh)

对选中文本或光标所在块发起 AI 问答，复用思源本体配置的模型，答案流式输出。在设置的「人工智能」中开启后生效。

## 功能简介

思源本体自带 AI 配置（模型 + API Key），这个功能让你不离开编辑器直接用：选中文字，或把光标放进块里，一键提问，答案在对话框中流式打出。

既支持在对话框内直接输入的临时提问，也可以把常用提示词保存为自定义提示词随时调用；不想要的提示词按住 Shift 点击即可删除。

## 快速上手：配置人工智能

本插件使用的是思源本体的 AI。

只需要配置模型和 API Key 即可。
