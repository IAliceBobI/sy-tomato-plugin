[番茄工具箱-帮助](https://my.feishu.cn/docx/IWPcd438yoL3C6xHC0xcOXDKnmh)

状态栏番茄钟在思源状态栏提供一个番茄计时器：点一下图标就开始计时，倒计时数字常驻状态栏；到点播放提示音、弹出随机内容，可自动循环工作与休息、按天记账番茄数、把专注时长写回文档，还能在计时中换上背景壁纸。在番茄工具箱设置的「番茄钟」板块开启并配置。

## 功能简介

在思源里长时间写作时，番茄工作法是个好搭档，但计时器通常在手机或另一个窗口：设定要切出去，到点的提醒也未必注意得到，一坐几个小时是常态。

状态栏番茄钟把完整的番茄流程放进了思源状态栏：点档位图标即开始计时，倒计时数字常驻可见，到点一声铃响、弹出一段休息内容；开启自动循环后，工作结束自动进入休息，休息结束再自动回到工作。空下来时，图标位显示今天的番茄数，今天专注了几轮、多少分钟，一眼可见。

适合以思源为主要工作区、想用番茄节奏管理专注的人：开始写作前点一下 25 分钟，到点用一声提醒和一段休息内容让自己真正起来走走。

## 快速上手

1. 在番茄工具箱设置的「番茄钟」板块打开「状态栏番茄钟」，状态栏上出现一排档位图标与今日统计。
2. 点一个时长图标（如 25）开始计时，状态栏显示倒计时数字。
3. 计时中再点当前档图标=暂停 / 继续；点 0 图标=取消。
4. 到点自动响铃并弹出内容；开启「工作/休息自动循环」则自动进入休息段，休息结束回到工作。
5. 按需配置提示音、随机内容、专注写回与计时壁纸（Pro），详见下文各节。

## 开始计时：状态栏图标与倒计时

[图片]

- **档位图标**：点击即以该时长开始计时；档位在设置中点选，可添加 1~240 分钟的自定义档，最多 8 档（每档占状态栏一个图标）。
- **暂停 / 继续**：计时中点当前档图标即暂停，再点恢复；暂停时倒计时带 ⏸ 标记。
- **取消**：点 0 图标取消当前计时。
- **倒计时**：计时中常驻显示剩余时间；空闲时该位置显示今日番茄数 🍅 N，点击查看「今日 N 番茄 · M 分钟」。
- **重启恢复**：计时中重启思源，剩余时间自动恢复，计时继续。

## 工作/休息自动循环

开启「工作/休息自动循环」并设置休息时长（分钟）后：工作段到点自动进入休息——状态栏倒计时带 ☕ 前缀，同时弹出休息小窗，顶部是休息倒计时，下方展示从「随机视频」文档里随机抽出的内容；休息到点小窗自动关闭，提示回到工作。

[图片]

循环模式下点击状态栏倒计时=跳到下一阶段（工作↔休息）；未开循环时点击=查看剩余时间。

## 到点提醒：提示音与随机内容

- **提示音**：内置默认（双音）、清脆铃、柔和钟声、木鱼双敲四种音色，选好后点「试听」即响；选「自定义」可填 http(s) 链接，或用「选择文件」把本地音频直接存进思源 assets。Windows 本地路径（如 `c:\abc.mp3`）浏览器内核不允许播放，面板上会标红提示，请改用 assets 或网络链接。
- **随机内容**：「随机视频」填一个思源文档名（不带路径与后缀），到点时从该文档及其子文档中随机挑一条内容展示，文字、图片、音频、视频、网页皆可。
- **关闭弹窗**：按 Escape 或点关闭按钮即收起。

到点的呈现方式：浏览器中为弹窗；桌面端默认弹出一个独立小窗（切到其他软件也能看到），勾选「禁用强提醒」后不再弹独立窗口，改为普通弹窗。

## 专注时长写入文档

开启「专注时长写入文档」后，每次开始计时都会绑定当前正在编辑的文档：这一段工作自然走完（跳段、取消不计），专注分钟数就累加写进该文档的属性 `custom-tomato-focus`，在文档的属性面板可查看累计值。文档已删除或写入失败时静默跳过，零打扰。

## 今日统计

空闲时状态栏显示今日完成的番茄数 🍅 N，点击查看「今日 N 番茄 · M 分钟」。只统计自然走完的工作段，按天累计、长期保留。

## 计时壁纸（Pro）

计时中为整个思源换上一张背景壁纸，明亮与黑暗主题各配一张：

- 支持「选择文件」把本地图片存进思源 assets，或直接填 http(s) 链接 / 站内路径；
- 「背景图透明度」滑块拖动时全屏实时预览：0% 全透明（相当于无背景），100% 完全不透明；
- 壁纸只在计时中显示（暂停时也在），休息段与空闲时自动撤下；计时中切换明暗主题即时换图。
