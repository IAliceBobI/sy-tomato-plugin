[番茄工具箱-帮助](https://my.feishu.cn/docx/IWPcd438yoL3C6xHC0xcOXDKnmh)

接力浮条把「双向互链 / 嵌入互链 / 关联两个块 / 互相插入引用 / 同步块 / 搬运」六个两步式块配对操作收进同一条浮条，采用**功能优先**的用法：唤出后先显示六个功能按钮，点选功能后浮条变成该功能需要的框，框齐按 ✓ 执行。从此不必记十余个「选择 / 创建」快捷键。在番茄工具箱设置的「块配对工具」分区开启。

## 功能简介

思源里有一类操作是「两步式」的：先在一个块上「选择」，再到另一个块上「创建」——双向互链、同步块、内容搬运都是这个套路。原生做法各配一对快捷键，加起来十余个，用得少根本记不住；每次翻设置或菜单又太慢。

接力浮条把这类操作整合成一条浮条：按 `⌥⇧V` 唤出后先选功能，浮条变成对应的框，点编辑器里的块（或把块拖进框）逐个填满，按 ✓ 执行。功能优先、框位引导，六个操作共用一个入口；熟手另有快捷键流（见下文），从唤出到执行全程不碰鼠标。

适合经常在块之间建立互链、同步副本或在文档间搬移内容的用户：源与目标可以不在同一篇文档，中途切换页签浮条不消失。

## 快速上手

1. 在插件设置「块配对工具」分区开启总开关。
2. 按 `⌥⇧V`（或点状态栏按钮、右键菜单）唤出浮条，先看到六个功能按钮，上次使用的功能会高亮。
3. 点一个功能按钮，浮条变成该功能需要的框：**搬运**=三框（起始 / 结束 / 目标）；其余五个功能=两框（源框可多块 + 目标框）。
4. 点编辑器里的块，填进高亮描边的「焦点框」；填完自动跳到下一个空框，框全满后焦点退出。
5. 框齐后 ✓ 主色按钮亮起并显示影响面预览（如搬运显示「移动 3 块」），点 ✓ 执行；✕ 或 Esc 取消收起。

## 怎么用（先选功能）

按 `⌥⇧V`（或状态栏按钮 / 右键菜单）唤出浮条，先看到六个功能按钮；在设置里配了「默认功能」时，出场直接跳到该功能的框态，跳过选功能这一步。

- 点一个功能按钮，浮条变成对应的框：高亮描边的框是「焦点框」——点编辑器里的块（或把块拖进框）填进它。
- 框齐后 ✓ 主色按钮亮起并显示影响面预览，点 ✓ 执行；✕ 或 Esc 取消收起。
- 搬运带「移动 | 复制」分段开关，当前项高亮；点框区左侧的功能图标回到功能面板换功能，换功能后框里的内容按映射自动重填。

## 填框的更多方式

- 出场时已有选区（含拖蓝多块）会先被记住，点完功能自动填框：两框整组进源框，三框首尾块进起始 / 结束框。
- 只有光标、没有选区时：两框照常把光标块填进源框；三框只填起始框，结束框留空自己选——想搬单个块，结束框再点一下同一个块即可。
- 既无选区也无光标时，最近用过的块（上次配对成功的首个源块）会自动填进第一框。
- 拖动块左侧把手把块拖进浮条=填对应框；拖源框里的块标签到编辑器某块上松手=填目标框。**拖放只填框不执行**，执行走 ✓ 或快捷键。
- 填错了点框旁的 ✕ 删掉重来；焦点落在已填框时直接点新块=覆盖。源框多块时显示「+N」计数徽标。

## 快捷键流（三步合一）

浮条出现后，每按一次 `⌥⇧V` 就把光标所在块（或当前选区）填进下一个空框，填满最后一个框时**自动执行**——熟手从唤出到执行全程不碰鼠标。

浮条停在功能面板（还没选功能）时按 `⌥⇧V`：收起浮条。Esc 或 ✕ 随时取消；源与目标可以不在同一篇文档，中途切换页签浮条不消失。

## 六个功能一览

- **双向互链**：两个块互相插入跳转链接，从任意一边可跳到另一边
- **嵌入互链 [Pro]**：在目标块下方创建源块的嵌入块
- **关联两个块**：两个块内互相插入对方的引用（或链接，随双向互链设置）
- **互相插入引用**：两个块下方互相插入对方的引用块
- **同步块**：建立同步副本，修改任意一处其余同步更新
- **搬运**：把起始到结束区间内的顶层块移动或复制到目标块之后；「删除」档只填起始 / 结束两框，删除区间内的全部顶层块（✓ 红色警示，且不记忆——每次出场先回到移动档）

## 小贴士

- 双向互链 / 关联两个块 / 互相插入引用只取源框的第一个块；同步块 / 嵌入互链 / 搬运会用上源框里的全部块。
- 拖动浮条背景空白区可挪位置，双击背景回到默认位；⋯ 菜单顶部有「快捷键速查」子菜单（互链族 / 同步块 / 长内容工具分组铺开全部快捷键，点任意项可直接执行对应命令），下面还有「链接到块底部 / 修复双向链接 / 删除双向链接」三个单块快捷功能和本帮助。
- 功能按钮置灰表示需要 Pro（嵌入互链带 Pro 徽标）；悬停功能按钮可看到该功能「选择 / 创建」对应的快捷键。
- 起始与结束跨文档、目标块落在搬运区间内部时会被拦截并提示；源与目标是同一块（或互为父子）同样拦截。
