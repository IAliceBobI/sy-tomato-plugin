[番茄工具箱-帮助](https://my.feishu.cn/docx/IWPcd438yoL3C6xHC0xcOXDKnmh)

DailyNote 工具用于日常笔记的收集与翻阅：把选中的内容一键移动或复制到今日 Daily Note，复制时可附带批注、阅读点等；配合 `Alt+Q` / `Alt+W` 可快速翻阅上/下一篇日志。在番茄工具箱设置的「DailyNote 工具」板块开启。

## 功能简介

写 Daily Note 最大的阻力是「搬运」：白天在各个文档里遇到的零碎想法，要手动剪切、粘贴到当日日志，来回切换打断思路；回头翻某天的记录，也得在文档树里层层展开。收集成本一高，日志很快就写不下去了。

DailyNote 工具把「收集」和「翻阅」都变成一步：`Shift+Alt+6` 把选中内容移动到今日日志底部（原文可自动改为链接），`Ctrl+Shift+6` 复制过去，复制时可选附带批注、阅读点，甚至加入闪卡；顶栏的 ⬅️ / ➡️ 图标或 `Alt+Q` / `Alt+W` 可在上/下一篇日志间快速切换。

适合把 Daily Note 当作收件箱的人：任何文档里看到值得记录的内容，一键归档到当天，之后凭日期即可回溯。

## 移动内容到 Daily Note（Shift+Alt+6）

快捷键 `Shift+Alt+6`。

[图片]

把光标所在的内容块或选中的所有内容，移动到今日 Daily Note 的底部。

该功能默认关闭，支持右键菜单与快捷键，请先在设置中开启。

> 仅移动选中的单行或多行内容；未选中时，移动光标所在的块。

## 复制到 Daily Note（批注功能）

打开配置后，可以从右键菜单或快捷键 `Ctrl+Shift+6` 中使用。
