块关系图把当前文档的块结构绘制成可交互的关系图：节点是块，连线是引用，图与文档可双向定位，还能在图中拖拽连线直接创建引用。在插件设置中开启「块关系图」总开关后可用。

## 功能简介

以编辑器为主要工具，辅以思维导图来编辑和维护内容。内容关系图能够直观展示文档内容的逻辑关系。文档与图中的节点可以实现双向定位，方便用户快速找到对应的内容。此外，还可以通过在图中添加连线的方式，为两个文档块建立引用关系。

思源全局关系图以文档为节点，看不到一篇文档内部的块结构；大纲只能看层级，看不到引用形成的网状关系。块关系图聚焦单篇文档：以块为节点、引用为连线，直观展示文档内部的逻辑关系。例如阅读一篇结构复杂的文章时，打开块关系图即可看清哪些段落相互引用、整体骨架如何组织。

结构连线（浅色虚线，体现标题、列表、容器与段落的父子骨架）与引用连线（主题色实线带箭头与锚文本标签）分层呈现：结构是背景板，引用是主角。不想要背景板时，可在设置中开启「隐藏结构连线」。

图是文档块的全集镜像：段落、标题、列表、代码块之外，嵌入查询、HTML、iframe、挂件、视频、音频、属性视图、分割线等无正文块也会全部进图（各带类型小图标与可读标签，如视频显示文件名、挂件显示挂件名），块与图节点的双向定位对全部块类型有效。

## 快速上手

1. 在插件设置中开启「块关系图」总开关，可同时开启「添加顶栏图标」与「添加右键菜单」。
2. 点击顶栏图标，或按快捷键 Shift+Alt+E（macOS 为 ⇧⌥E）打开当前文档的块关系图。

## 图中的基本操作

- 在图中

  - 按住 Ctrl 可以多选节点与连线
  - 拖动节点下方的出口连接另一节点的入口，即可为两个块创建引用
  - 单击节点：编辑器中对应块轻联动高亮（不滚动、不抢焦点）
  - 双击或 Alt+点击节点：滚动定位到文档中的对应块
  - 节点右键菜单：在编辑器中显示 / 打开所在文档 / 展开或折叠此节点 / 复制块 ID / 复制为引用
  - 引用连线右键菜单：复制锚文本 / 删除此引用
  - Backspace 删除选中的节点与连线（会真实改动文档，见「添加、删除边」）
  - 鼠标滚轮缩放、空白处拖拽平移；节点数较多时右下角出现缩略图小地图
- 在文档中

  - 右键菜单「定位到图中的节点」，或按 Ctrl+Alt+E（macOS 为 ⌘⌥E）

> 另外：快速创建引用可以用`双向互链`功能

## 如何刷新

图会自动刷新：切换文档立即跟随，编辑内容后数秒内同步。刷新前先比对文档的更新时间戳，内容没有变化就不重建——缩放、平移、折叠状态都不会被打扰。

超大文档（超过「最大节点数量」）打开时自动改用「标题骨架」轻量显示：只拉取标题行，秒开，引用连线照画。需要看全部块时，点提示条上的「完整加载」。

[图片]

进入完整加载后自动刷新暂停（避免反复全量构建卡顿），改用面板右上角「刷新」按钮手动重建。

## 折叠与展开

带子节点的节点右上角有 ⊕ / ⊖ 角标（附子节点计数），点击即可折叠 / 展开子树。折叠只影响显示，不改动文档内容。

折叠状态按文档记忆：下次打开同一文档，保持上次的折叠状态。首次打开的文档按设置的「默认展开层级」展开（见「配置」）。

在文档中定位一个折叠在子树深处的块时，会自动展开它的祖先节点，并高亮目标节点。

## 布局形态

树有四种生长形态，点击面板顶栏的「切换布局形态」按钮循环切换：横排向右 → 横排向下 → 竖排向右 → 竖排向下。「竖排」指节点文字竖排，适合在窄面板里纵向铺开多层子节点。

布局形态按文档记忆，也可在设置中为没记忆过的文档指定默认形态。

## 配置

[图片]

### 最大连续段落块数量

查看文档图时，如果注重整体的框架，可以设置`最大连续段落块`的数量，超出部分不显示。

### 最大节点数量

超过最大节点数量的超大文档会自动改为「标题骨架」轻量显示，需要看全部块时点骨架提示条上的「完整加载」（见「如何刷新」）。

### 默认展开层级

首次打开文档时，标题树默认展开到第几层（1 / 2 / 3 / 全部）。手动折叠过的文档以自己的折叠记忆为准，不受此项影响。

### 默认布局形态

没切换过布局形态的文档，首次打开时用哪种形态（见「布局形态」）。

### 隐藏结构连线

开启后只显示引用形成的连线，隐藏标题、列表、容器、段落之间的结构虚线。默认关闭——结构是关系图的骨架，建议保持显示。

## 引述块

引述块在图中作为一个容器节点展示，子内容收纳其中（与超级块同族样式，标题栏带 │ 引述块标记）：

[图片]

## 超级块

超级块在图中作为一个容器节点展示，子内容收纳其中，标题栏显示其布局方向（↗ → ↘）。

## 列表与段落块

列表在图中呈脑图式树形分叉：每个列表项是一个节点卡（列表项图标+项内文字），嵌套列表项作为子节点从父项分叉出去，兄弟节点自上而下按文档顺序排列；有序项带序号前缀（如「1.」），任务项带勾选框前缀（☐ 未勾 / ☑ 已勾）。连续的段落块会合并为一张 ¶×N 大卡片（悬停看全文），但列表、标题、引述块、超级块等承载结构的块不参与合并：

## 带标题的内容

`块关系图`一定程度可以替代`大纲`：各级标题沿树干层层展开，正文块挂在所属标题之下。

[图片]

## 添加、删除边

节点下方为出口，上方为入口。可以拖动一个节点的出口，连接另一节点的入口，即为两个块建立引用。

选中边或节点后，按 Backspace 删除。注意：删除引用连线会移除两个块之间的引用关系；删除节点会真正删除文档中的块（可从回收站找回），请谨慎操作。

引用连线也可以右键「删除此引用」，删除前有确认提示。

[视频]

## 图与文档双向定位

在文档中定位图中节点：按 Ctrl+Alt+E（macOS 为 ⌘⌥E），或使用右键菜单。目标在折叠子树中会自动展开并高亮。

在图中单击节点即可在编辑器中轻联动高亮对应块；双击或 Alt+点击节点可滚动定位到相关块，也可使用右键菜单。
