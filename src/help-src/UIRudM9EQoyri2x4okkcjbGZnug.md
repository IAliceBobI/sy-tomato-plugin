[番茄工具箱-帮助](https://my.feishu.cn/docx/IWPcd438yoL3C6xHC0xcOXDKnmh)

块关系图把当前文档的块结构绘制成可交互的关系图：默认展示文档的**结构骨架**（标题、列表、引述、超级块），段落内容收成小卡片、点开才展开，连线是引用，图与文档可双向定位，还能在图中拖拽连线直接创建引用。在插件设置中开启「块关系图」总开关后可用。

## 功能简介

思源全局关系图以文档为节点，看不到一篇文档内部的块结构；大纲只能看层级，看不到引用形成的网状关系。块关系图聚焦单篇文档：以块为节点、引用为连线，直观展示文档内部的逻辑关系。例如阅读一篇结构复杂的文章时，打开块关系图即可看清章节骨架如何组织、哪些段落相互引用。

图分四个视图档，面板顶栏一排平铺按钮单击直切（当前档高亮，「全部块」按钮在分隔线后单独一组）：

- **结构视图（默认）**：只画承载结构的骨架块——文档根、标题、列表项、超级块、引述块；段落等正文叶子收进所属章节的「N 段 · X 字」徽标，点开才展开。打开即读：不需要在大片段落节点里找结构，一章有几个自然段、多少字一眼可见。标记感知：你划过线/标记过的路径自动展开到所在章节（详见「标记感知展开」）。
- **只看标记**：从结构树里只留标记路径——标记块成卡片、父级章节链连到文档根，其余分支不出现；标记少于 30 处全部摊开，更多时收成「● N」角标点击展开（详见「只看标记」）。行内划线、文字背景色、自定义颜色（任意色值）、块级标记全部识别。
- **方块总览**：把文档画成磁盘清理工具式的矩形树图——一章一块矩形，面积=字数，哪章厚一眼看出。
- **全量视图**：文档全部块都进图，适合细看某一段落的引用去向。大文档切全量前会先确认（见下文）。

档位按文档记忆：每个文档记住你上次选的视图档，下次打开直接恢复；没选过的文档一律从结构视图开始。

两种树形档（结构/全量）下，引用连线（主题色实线带箭头与锚文本标签）与结构连线（浅色虚线，体现骨架块之间的父子关系）都分层呈现：结构是背景板，引用是主角。不想要背景板时，可在设置中开启「隐藏结构连线」。

## 快速上手

1. 在插件设置中开启「块关系图」总开关，可同时开启「添加顶栏图标」与「添加右键菜单」。
2. 点击顶栏图标，或按快捷键 Shift+Alt+E（macOS 为 ⇧⌥E）打开当前文档的块关系图。
3. 打开就是结构视图；面板顶栏的四个视图按钮（结构视图 / 只看标记 / 方块总览 / 全部块）单击直切。

## 结构视图：打开即读的骨架

[图片]

- **骨架块**：文档根、标题、列表项、超级块、引述块直接成节点；标题树直接取思源的大纲数据（跟左栏大纲面板完全一致），正文按文档序归给前方最近的标题。
- **内容徽标**：章节直属的段落叶子收成一枚「N 段 · X 字」徽标挂在节点下方，点击展开成内容卡片，再点收起。
- **内容卡片**：展开后每段一张卡——主色标题栏（类型图标+首行）+多行正文（超过约 8 行自动截断，悬停看全文）。
- **章节自动编号**：标题节点带 1、1.1、1.1.1 式的浅灰编号前缀，层级一目了然；不需要时可在设置关掉「章节自动编号」（文档自带编号时建议关闭，避免双编号）。
- **引用照画**：段落还没展开也不影响——引用连线直接画在徽标所属的章节节点上，谁的段落被引用一眼可见。
- **大文档秒开**：结构视图走轻量数据通道，上千块的文档也是毫秒级出图。
- **无结构文档**：既没有标题、也没有列表等容器的纯平铺文档，图区中央显示提示卡——一键转「方块总览」看段落分布，有标记则同时给「只看标记」入口；点「知道了」本次会话不再提醒。
- **层级自适应**：文档没有 H1（章从 H2 起步）时按文档内实际的最小标题级别展开，不会把小节全折进徽标。
- **标记感知展开**：打开文档时，你划过线、上过色的路径自动展开到所在章节——标记在哪一眼可见。含标记的节点带「● N」角标（N=子树标记数，色点=标记颜色）：标记叶少于 30 处直接摊开成卡片；更多时收着，点角标展开该章节的标记叶（再点收起）；点折叠节点上的角标则先展开该节点。标记路径占用的展开容器总量有上限，超预算的路径先收着（角标仍在，点击可达）。

## 全量视图：显示全部块

顶栏「全部块」按钮切换到全量视图：

- 小文档零等待直接切换（数据已备好，来回切不重建）；大文档会弹出「完整加载大文档？」确认，避免一次性渲染卡顿。
- 全量视图包含文档块的全集：段落、标题、列表、代码块之外，嵌入查询、HTML、iframe、挂件、视频、音频、属性视图、分割线等无正文块也会全部进图（各带类型小图标与可读标签）。
- 连续的段落块合并为一张 ¶×N 内容卡（链内全文合并展示，最多合并「最大连续段落块数量」设置指定的段数）。
- 点「结构视图」按钮切回默认档；选过全量的文档在本次会话内会记住你的选择，重开思源后恢复结构默认。

## 方块总览：一眼看出哪章厚

大文档在树形视图里会被拉得很长（几百块竖着排到天边），方块总览换一种画法——磁盘清理工具式的矩形树图：

[图片]

- **一章一块**：一级矩形=章（颜色按色轮轮换），章内每个内容块是一小块叶子矩形，铺满所属章节。整张图永远铺满面板，不会无限拉长。
- **面积=字数**：章节和段落的面积都按字数分配，哪章厚、哪段长一眼看出；太小的叶子（不足几个像素）自动归并进章节底色，巨书也不卡。
- **双击下钻**：双击章节矩形，该章子树铺满整张画布细看；顶部出现「文档 › 章 › 节」面包屑，点击任意一级返回。
- **选中看详情**：单击矩形选中；如果这个块有引用关系，其余矩形压暗、它引用的块（主题色虚线描边）与引用它的块（强调色虚线描边）亮起，底部工具条列出「引用 N 处 / 被 M 处引用」，点击条目直接跳到原文对应位置。点空白处或按 Esc 取消。
- **大文档也好用**：整张图铺满面板不拉长，巨书也秒开；随时点「方块总览」按钮进入。

## 只看标记：你的知识地图

从整棵结构树里只留标记路径——标记过的内容块挂上父级章节链、连到文档根，其余分支全部隐去：

[图片]

- **识别范围**：思源的行内划线（==高亮==）、文字背景色全部识别，包括自定义颜色（任意色值，不限官方色板）；划线总览的颜色分组同步支持自定义色。整块挂过「块级标记」的块也计入（见下节），同块既有划线又有块标记算一处。
- **标记叶=两段卡**：每个标记块渲染成内容卡片（标题栏染你标记时的颜色），单击卡片直接跳回原文位置；点空白处不打扰，双击同样可跳。
- **结构骨架保留**：标记所在的章节链全部保留并自动展开，折叠/展开操作照常可用（它就是同一棵结构树，只是过滤了无标记分支）。
- **标记多时收着**：标记叶少于 30 处时全部摊开；更多时章节收拢、节点带「● N」角标，点击角标展开该章节的标记叶（再点收起）——标记再多也不刷屏。
- **还没有标记**：整篇没标记时显示提示卡，划线或加背景色后这里就成了你的知识地图。

入口=顶栏「只看标记」按钮。结构视图里的「● N」角标与本章同一套标记感知（见上节）。

## 块级标记：给整块挂重点

不用选中文字设色，直接给整个块挂一枚标记：

- **打标**：光标放在块内，右键菜单点「标记此块」，或按快捷键 Ctrl+Alt+Shift+M（macOS 为 ⌘⌥⇧M）；再按一次取消标记。
- **正文反馈**：被标记的块左缘出现一条淡色细竖条，翻文档时一眼看到哪些块挂了重点；不需要可在设置关掉「标记块正文左边条」。
- **进图**：块级标记与行内划线一起计入「只看标记」视图——既能划线也能整块挂标，混合使用都识别。
- **数据随块走**：标记存在块属性里，块删除标记随之消失，零残留。

## 图中的基本操作

- 在图中

  - 按住 Ctrl 可以多选节点与连线
  - 拖动节点下方的出口连接另一节点的入口，即可为两个块创建引用
  - 单击节点：编辑器中对应块轻联动高亮（不滚动、不抢焦点）
  - 双击或 Alt+点击节点：滚动定位到文档中的对应块
  - 节点右键菜单：在编辑器中显示 / 打开所在文档 / 聚焦此块 / 展开或折叠此节点 / 复制块 ID / 复制为引用
  - 聚焦：右键节点点「聚焦此块」，或在文档中把光标放在块内按 Ctrl+Alt+Shift+F（macOS 为 ⌘⌥⇧F）——目标块连同父链、兄弟、子块与引用连线高亮，其余淡化半透明，图不重排；点空白处或再按一次恢复全景
  - 引用连线右键菜单：复制锚文本 / 删除此引用
  - Backspace 删除选中的节点与连线（会真实改动文档，见「添加、删除边」）
  - 鼠标滚轮缩放、空白处拖拽平移；节点数较多时右下角出现缩略图小地图
- 在文档中

  - 右键菜单「定位到图中的节点」，或按 Ctrl+Alt+E（macOS 为 ⌘⌥E）

> 另外：快速创建引用可以用`双向互链`功能

## 如何刷新

图会自动刷新：切换文档立即跟随，编辑内容后数秒内同步。刷新前先比对文档的更新时间戳，内容没有变化就不重建——缩放、平移、折叠状态都不会被打扰。

全量视图（大文档确认过「完整加载」）进入后自动刷新暂停（避免反复全量构建卡顿），改用面板右上角「刷新」按钮手动重建；切回结构视图后恢复自动跟随。

## 折叠与展开

全量视图中，带子节点的节点右上角有 ⊕ / ⊖ 角标（附子节点计数），点击即可折叠 / 展开子树。折叠只影响显示，不改动文档内容。

折叠状态按文档记忆：下次打开同一文档，保持上次的折叠状态。首次打开的文档按设置的「默认展开层级」展开（见「配置」）。

在文档中定位一个折叠在子树深处的块时，会自动展开它的祖先节点，并高亮目标节点；结构视图下目标块尚在徽标里时，按提示先完整加载或展开对应章节再定位。

## 布局形态

树有四种生长形态，点击面板顶栏的「切换布局形态」按钮循环切换：横排向右 → 横排向下 → 竖排向右 → 竖排向下。「竖排」指节点文字竖排，适合在窄面板里纵向铺开多层子节点。

布局形态按文档记忆，也可在设置中为没记忆过的文档指定默认形态。

## 配置

### 最大连续段落块数量

全量视图中连续段落合并为 ¶×N 内容卡的段数上限；注重整体框架时可以调小。

### 最大节点数量

全量视图的节点数上限。超大文档切「显示全部块」时会提示确认，就是为越过这道闸的文档准备的。

### 默认展开层级

全量视图首次打开文档时，标题树默认展开到第几层（1 / 2 / 3 / 全部）。手动折叠过的文档以自己的折叠记忆为准，不受此项影响。

### 默认布局形态

没切换过布局形态的文档，首次打开时用哪种形态（见「布局形态」）。

### 隐藏结构连线

开启后只显示引用形成的连线，隐藏骨架块之间的结构虚线。默认关闭——结构是关系图的骨架，建议保持显示。

### 章节自动编号

结构视图的标题编号前缀（1 / 1.1）开关，默认开启。

### 标记块正文左边条

挂过「块级标记」的块在正文里左缘显示淡色竖条（见「块级标记」一节），默认开启。

## 引述块与超级块

引述块、超级块在图中作为容器节点展示，子内容收纳其中（超级块标题栏显示布局方向 ↗ → ↘）。结构视图下它们是骨架的一部分：直属段落收进徽标，展开即读。

## 带标题的内容

`块关系图`一定程度可以替代`大纲`：结构视图下各级标题沿树干层层展开、带自动编号，正文收在所属章节的徽标里，点开即读——比大纲多出引用关系线，比全局搜索更直观。

## 添加、删除边

节点下方为出口，上方为入口。可以拖动一个节点的出口，连接另一节点的入口，即为两个块建立引用。

选中边或节点后，按 Backspace 删除。注意：删除引用连线会移除两个块之间的引用关系；删除节点会真正删除文档中的块（可从回收站找回），请谨慎操作。

引用连线也可以右键「删除此引用」，删除前有确认提示。

## 图与文档双向定位

在文档中定位图中节点：按 Ctrl+Alt+E（macOS 为 ⌘⌥E），或使用右键菜单。目标在折叠子树中会自动展开并高亮。

在图中单击节点即可在编辑器中轻联动高亮对应块；双击或 Alt+点击节点可滚动定位到相关块，也可使用右键菜单。
