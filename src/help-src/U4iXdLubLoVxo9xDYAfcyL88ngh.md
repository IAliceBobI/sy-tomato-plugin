知识库把你的笔记文档同步到智谱 BigModel 知识库：向量化、检索、问答都在平台侧完成，插件只做「同步管道 + 问答入口」。适合让 AI 基于你自己的笔记回答问题——检索命中的内容带来源文档名，可直接定位回思源原文。

在插件设置的「知识库」分区（设置 → 番茄 → 知识库）开启总开关后可用。

## 快速上手

1. 准备一个智谱 API Key：[注册账户](https://bigmodel.cn/login)（登录页兼注册，手机号自动建号）→ [创建 API Key](https://bigmodel.cn/apikey/platform)。
2. 设置 → 番茄 → 知识库：填入 Key，点「连通性测试」看到容量信息即通。库名可不填（默认自动建一个）。
3. 在文档树右键一篇文档 → 「同步到知识库」：这篇文档**和它的全部子文档**会递归加入同步白名单。
4. 打开知识库面板（快捷键 ⌥F10 / Alt+F10，或右侧 dock「知识库同步」图标），点「立即同步」。首次同步会自动建库并上传、向量化。
5. 同步完成后，在面板下方「向知识库提问」输入框提问即可，回答流式显示。

费用参考：平台存储 1GB 永久免费；向量化 0.5 元/百万 token（约 400 万字全量同步一次 ≈ 3 元，之后每轮增量只有几分钱）；问答按所用模型计费。[查看平台计费规则](https://docs.bigmodel.cn/cn/guide/tools/knowledge/price)。已同步的库与文件可在[知识库控制台](https://bigmodel.cn/console/appcenter_v1/knowledge)查看。

（图：知识库面板双区——上半区同步白名单与「立即同步 / 检查变更」，下半区「向知识库提问」流式回答）

## 文档树上的「在库内」标记

加入白名单后，文档树行尾会出现标记，一眼看出哪些内容在库里：

- **状态点**（白名单条目自身）：蓝点=已同步（悬停看同步时间）；黄点=内容有变更待同步；红点=同步失败；空心点=已加入但还没同步过。
- **浅标**（条目子树内的子孙文档）：说明它随父条目在库里，但不是条目本身。
- **⊘**：该文档被排除（见下节），它和它的子孙都不会入库。

知识库面板的白名单条目上还会显示「📁N篇·排M」徽章：N=这个条目实际会同步的篇数（含自己），M=其中被排除的篇数。

（图：文档树行尾标记——蓝点已同步 / 黄点待同步 / 红点失败 / 空心点未同步，子树浅标与 ⊘ 排除标一眼可辨）

## 移出与排除：两个不同的语义

- **移出知识库同步**（文档树右键）：把条目从白名单摘掉，以后不再同步它。**平台侧已同步的内容会保留，不会被删除**——需要清理可去知识库控制台手动删除。
- **从知识库排除**（文档树右键，白名单条目的子文档上）：这个文档**和它的全部子文档**不再入库。与「移出」不同：排除是参与同步语义的——平台侧对应内容会在下次同步时被自动替换或移除；如果一个条目下的内容被全部排除，平台侧这个条目的副本会被主动清空。想恢复，对排除的文档右键「取消排除」即可。

简单记：**移出=我不管它了（平台上留着）；排除=把它挡在库外（平台上也拿掉）**。

（图：文档树右键「从知识库排除」与面板徽章「📁N篇·排M」前后对照）

## 同步机制

- 同步是增量的：每个文档按内容指纹比对，没变的跳过，只有变化的部分重新上传向量化。
- 自动同步：默认每 30 分钟自动检查一次变更并同步，间隔可在设置里调整。
- 手动：面板上的「检查变更」只比对不动手，「立即同步」检查并推送变更。
- 同步范围控制：**笔记本（整本）不能加入**，只能按文档加入——防止一不小心把整本笔记外发。排除机制（见上）用来在条目内部挖洞。

## 让 AI 检索你的知识库（MCP 工具）

知识库同时暴露成两个 MCP 工具，任何能接思源 MCP 的 AI 工具（ZCode、Claude、Cursor 等）都能用：

- `knowledge_search`：在知识库中检索，返回最相关的原文切片（相似度分数 + 来源文档名；docID 非空时可直接定位回思源文档）。适合让 AI 回答「与你自己笔记内容相关」的问题。
- `knowledge_status`：查看知识库状态——是否已配置、容量用量、已同步文档数与向量化进度。

接入方式与思源 MCP 一致（详见 AI 助手帮助篇的接入引导）。工具在 MCP 列表里的名字带 `plugin__sy-tomato-plugin__` 前缀和随机后缀（如 `plugin__sy-tomato-plugin__knowledge_search__xxxx`），以工具列表实际显示为准。注意：MCP 面是只读的，不会替你建库——先在面板完成一次同步，库存在后工具即可检索。番茄自带的 AI 助手面板也自动拥有这两个工具。

## 设置项一览

都在 设置 → 番茄 → 知识库：

| 设置项 | 说明 |
|---|---|
| 知识库同步 | 总开关，关掉后面板、右键菜单、自动同步全部停用 |
| 右键菜单：同步到知识库 | 文档树右键入口的开关（带快捷键 ⌥F10 帽） |
| 自动同步间隔 | 分钟数，默认 30 |
| 智谱 API Key | 通道凭证，password 框 |
| 库名 | 可选，改名会重建库（重新上传） |
| 连通性测试 | 测试 Key 并显示账户容量 |

## 注意事项

- 同步会把文档内容（转成 Markdown 后的正文）上传到智谱平台侧。白名单范围请自行斟酌，敏感内容不要加入。
- 问答、检索消耗的是你自己的智谱账户额度（同插件 AI 助手的 Key 体系）。
- 平台侧知识库也可在控制台直接管理（删除文件、重建等）；手动删除后下次同步若内容未变不会自动重传（内容变了才会）。
