[番茄工具箱-帮助](https://my.feishu.cn/docx/IWPcd438yoL3C6xHC0xcOXDKnmh)

工作空间导出助手把当前工作空间（笔记本）持续导出为标准 Markdown 文件，供 Trae、CherryStudio 等 AI 工具建立索引与问答。在插件设置中开启「导出工作空间」总开关后可用。

## 功能简介：从 .sy 到可索引的 Markdown

目标： 将思源笔记（Siyuan）的内容作为知识库源，供 Trae 或 CherryStudio 等工具进行索引和问答。

挑战： 思源笔记默认使用基于 JSON 的.sy 格式存储笔记，该格式不利于 Trae、CherryStudio 等工具直接建立索引。

方案： 将思源笔记内容定期导出为 Markdown（.md）格式，供索引工具使用。

## 快速上手

1. 在插件设置中开启「导出工作空间」总开关，并设置「导出工作空间到此文件夹」。
2. 可用白名单 / 黑名单控制导出范围；为空时可在文档树中右键添加文件夹或文档。
3. 手动执行：设置中的「全量导出 / 增量导出 / 确保导出符合配置」按钮，或快捷键 Alt+F8 全量导出、Alt+F6 增量导出、Alt+F7 确保导出符合配置（macOS 为 ⌥F6/F7/F8）。
4. 自动化（推荐 [VIP]）：开启「每 x 秒执行一次增量导出」，笔记改动后自动更新导出目录中的 .md 文件。

## 配置步骤

### 第一步：导出思源笔记为 Markdown 格式

[图片]

**工具准备：**确保已安装思源笔记的插件「番茄工具箱」。

**执行导出：**

- 在思源笔记中，使用“番茄工具箱”提供的 “导出工作空间” 功能。
- 将当前打开的工作空间（笔记本）导出到指定的本地目录。
- 此功能的核心作用是将思源原生的 .sy 格式笔记转换并导出为标准的 Markdown（.md）文件。

**自动化同步（推荐）：**

- 在“番茄工具箱”的导出功能设置中，启用增量导出。
- 配置增量导出的时间间隔（例如：每 1 分钟）。
- 作用： 启用后，工具箱会持续监控思源笔记的改动。每当有笔记被修改，工具箱会在设定的时间间隔（如 1 分钟）后，自动将该笔记的最新内容重新转换为.md 格式并更新到指定的导出目录。这确保了外部知识库索引能相对实时地更新。

[图片]

### 第二步：配置索引工具

- 对于 Trae:

1. 下载并安装 Trae。
2. 启动 Trae。
3. 在 Trae 中，打开第一步中指定的导出目录（即包含转换后.md 文件的目录）。
4. Trae 会自动开始扫描该目录并建立索引。等待索引完成。
5. 索引建立后，即可：

- 对整个知识库目录的内容进行提问。
- 对特定的文件或文件夹进行提问。
- Trae 检测到 md 有更新时，会针对更新自动重建相关的索引。

[视频]

经过实测，索引与问答效果不错。

- 对于 CherryStudio（类似操作）：

1. 下载并安装 CherryStudio。
2. 启动 CherryStudio。
3. 在 CherryStudio 中添加知识库。
4. 在添加知识库时，选择第一步中指定的导出目录作为知识库源路径。
5. CherryStudio 会扫描该目录并建立索引。
6. 索引建立后，即可通过 CherryStudio 对知识库内容进行提问。

- 番茄工具箱更新 md 后，CherryStudio 通常不会自动重建索引，需要手动触发。

[图片]

## 流程总结

1. 思源笔记变更 -> (自动触发) 番茄工具箱增量导出 -> (生成/更新) 导出目录中的.md 文件。
2. .md 文件变更 -> (自动触发) Trae 索引重建 -> (更新) 知识库索引。
3. 用户通过 Trae/CherryStudio 对最新的知识库索引进行提问。
