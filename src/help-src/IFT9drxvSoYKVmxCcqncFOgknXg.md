悬浮球是可放置在思源界面任意位置的快捷按钮：单击触发绑定的动作，按住拖到顺手的角落，右键打开管理菜单。在番茄工具箱设置的「速记」板块开启，桌面端与移动端分别启停。

思源里的高频操作大多依赖快捷键，可一旦离开键盘——移动端没有物理键盘，桌面上也总有双手离不开鼠标的时刻——这些入口就都够不着了；每天要打开的文档（计划本、日记、速记本）每次都得去文档树里翻找，入口太深。悬浮球把这些入口变成一颗颗摆在明面的按钮：绑定快捷键的球点击等价于按下该键，移动端因此也能用上键盘专属功能；绑定文档的球一点即开、再点即关。日常放两三颗最常用的入口，比多记一堆快捷键更省心。

## 球的类型

| 类型 | 触发效果 | 添加入口 |
| --- | --- | --- |
| 文档球 | 打开/关闭绑定的文档（新页签、对话框（点外自动关）、悬浮窗三种打开方式） | ➕文档（搜索选择器） |
| 当天日记球 | 每次点击新建并打开当天日记（文档球的特殊形态） | ➕当天日记（选打开方式一键添加） |
| 官方快捷键球 | 按下思源内置快捷键（如 ⌘P 全局搜索） | ➕官方快捷键（命令列表跟随界面语言，中英文都能搜） |
| 插件命令球 | 执行番茄工具箱的命令 | ➕插件命令（命令列表） |
| 任意键位球 | 按下你手录的任意键位组合 | ➕快捷键 |
| 外链球 | 打开网址（默认浏览器 / 思源内打开两档） | ➕外链 |

## 球的交互

- **单击**：执行绑定动作（文档球再点关闭；对话框/悬浮窗形态切换显隐）。
- **按住拖动**：拖到任意位置；拖近屏幕四角时出现虚线提示，松手自动吸附到该角。
- **右键**：球菜单——编辑（图标/名称/大小/透明度/常显标签+类型专属字段）、停用/启用、删除。移动端**长按**打开同一菜单。
- **位置记忆**：每颗球位置独立记忆，桌面端与移动端各自独立。
- **⌘⇧F8 显示/隐藏悬浮文档**：一键唤起或收起最近使用的悬浮窗形态文档球——速记场景放一颗悬浮文档球常驻，键盘直达不用鼠标找球，快捷键可在设置里改。悬浮窗顶部的三个操作钮（解除绑定 / 收起 / 定位原文）固定在窗顶不随内容滚动。
- **悬浮文档打开时跳到底部**（设置「速记 → 悬浮球」，默认关）：开启后每次打开悬浮文档都落到文档底部，光标自动停在末尾——打开即可直接打字续写（底部留一段空白，末行不贴窗口底边）；关闭则回到上次看到的位置。
- **悬浮文档打开后保留悬浮球**（设置「速记 → 悬浮球」，默认关）：开启后点球打开悬浮窗时球留在原地，再点一下即关窗（与 ⌘⇧F8 同效）；关闭则维持「开窗时球让位消失」。

**限制：**任意键位球部分快捷键无法绑定（如 Ctrl+Q、F1～F12、Alt+F1 等），遇到时请更换其他键位组合。

## 外观

每颗球可独立配置：大小三档（28/36/44px）、透明度（悬停时恢复全显）、是否在球下方常显名称标签。配色跟随思源明暗主题自动适配。

在番茄工具箱设置的「速记」板块打开「悬浮球」总开关，用 ➕ 按钮添加第一颗球：

点击`保存并退出`，即可获得一个悬浮球：

### 举例2：遍历 Daily Note（桌面端与移动端通用）

先在「DailyNote 工具」中开启功能，激活两个遍历日志的快捷键，再把快捷键绑定到悬浮球，桌面端与移动端都可以方便地翻阅日志。

[图片]

### 举例3：放一颗 ⌘P（官方快捷键球）

搜索 keymap 中的「全局搜索」，点击即得一颗全局搜索球——移动端也能随时唤起。

### 举例4：绑定计划文档（文档球）

用 ➕文档 的搜索选择器选中计划文档，选择打开方式（推荐悬浮窗）。绑定时自动记录文档 ID，重名或改名都不影响打开。

## 管理：设置面板球列表

设置面板的球列表支持**拖拽排序**（顺序即挂载顺序），每行提供桌面端/移动端启停开关、编辑与删除按钮。

**收费说明**：悬浮球功能免费开放，每类（文档类/其他类）最多同时挂载 3 颗；超出数量的球仍在列表中可见（置灰+VIP 标记+解锁按钮），解锁 Pro 后全部挂载。

## 进阶用法：悬浮球 + Daily Note 动态计划系统

[图片]

一种核心玩法：把 Daily Note 与悬浮球绑定的计划文档配合起来，形成动态、可调整的计划管理体系。

1. **计划文档管长期与优先级**：Daily Note 每日生成新文件，天然不适合存放需长期跟踪的任务。把一个固定的计划文档绑定到悬浮球，即可一键打开关闭；文档内用层级列表管理任务——最优先的放列表顶端，优先级随时上下移动调整，任务衍生出子分支时直接在下方添加子列表项细化。
2. **Daily Note 管当日执行与记录**：记录每天的实际执行情况——学习/工作内容与进展、生活事项与感悟、当日实际完成的任务（可能来源于计划文档）。
3. **两者形成闭环**：计划文档提供目标指引与待办池，负责宏观框架与动态优先级；Daily Note 反馈执行状态并可能催生新任务或调整需求。这种分离设计解决了长期计划与短期执行的矛盾，兼具目标导向与执行反馈，还能通过动态排序+子任务灵活响应变化。
