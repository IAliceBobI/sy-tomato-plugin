[番茄工具箱-帮助](https://my.feishu.cn/docx/IWPcd438yoL3C6xHC0xcOXDKnmh)

批注功能用于给笔记正文中的词语、多行文本乃至整段块添加批注：批注内容保存在原文块的属性里，与文档同进退，不额外占用笔记文档；点击原文中的标记即可查看与编辑。在插件设置中开启「批注」总开关（默认关闭）后可用。

## 功能简介

思源笔记本体没有专门的批注功能：想对正文词句写下想法，只能直接修改原文或另开文档记录，批语与正文混在一起，回看时难以区分，也容易破坏原文的完整性。

批注功能将两者分离：选中正文文本，通过划词工具条、右键菜单或快捷键添加批注，批注内容连同时间一起保存在**原文块属性**中——批注跟随原文块移动、复制与同步，删除原文块即连带删除其批注；原文处仅添加样式标记，文字本身不被改动。

点击正文中带标记的文本，气泡直接展示批注，右侧侧边栏（Dock）的批注分区列出当前文档全部批注；侧边栏还集成了引用、反链与更强大的实时虚拟引用——无需手动刷新、随写随查。例如写小说时输入人物名，侧边栏立即显示该人物的相关批注与提及。

## 快速上手

1. 在插件设置中开启「批注」总开关（默认关闭），按需勾选「添加右键菜单」。
2. 选中正文的词语或多行文本，点击划词工具条上的批注按钮，或右键选择「添加批注」、按快捷键 ⇧⌥F。
3. 在弹出的批注编辑器中输入内容，Ctrl/⌘+Enter 保存。
4. 点击正文中带标记的文本：气泡即时展示批注，可编辑、问 AI 或删除；批注面板则汇总当前文档全部批注，点击任意条目定位回原文（⌥⌘S 打开右侧批注面板）。
5. 想整档带走时，用「收集批注」一键归档到当天日记 / 指定文件 / 剪贴板（见下文「批注收集」）。

## 添加批注：划词工具条、右键菜单或快捷键

- **划词工具条：**选中文本后，思源自带的划词工具条上直接出现「添加批注」图标按钮，点击即开批注编辑器；与右键菜单相互独立，可在设置中分别关闭，快捷键不受影响。
- **右键菜单：**选中文本后右键选择「添加批注」（可在设置中关闭该菜单项，不影响快捷键）。
- **快捷键：**⇧⌥F（Windows/Linux 为 Shift+Alt+F）。

批注支持两种粒度：

- **选区批注（划选）：**选中一个或多个词语、一句话，批注挂在划选的片段上；跨多个段落拖蓝划选文字仍属选区批注（标记分布在各段）；
- **块级批注（整块）：**以块选择模式（Esc 块选 / 点块图标）选中一个或多个块，或不划选文本直接触发快捷键（批注挂光标所在块），弹窗标注「块级 · N 个块」，面板列表中带「块级」徽标。

批注创建弹窗里可勾选**闪卡**，把被批注的原文块加入思源闪卡复习（默认不勾选）。

## 批注编辑器：双模式

编辑器上方的工具条左端是模式分段钮（即切即记，下次开弹窗直接进入上次模式），右端是字号 A−/A+ 调节：

- **富文本（默认）：**内嵌思源 Protyle 编辑器，批注正文可加粗、着色、插公式与块引用，是完整的思源富文本；
- **纯文本：**跳过草稿块与编辑器挂载整条链，弹窗近乎秒开，专注码字。

两种模式的「问 AI」、闪卡开关、Ctrl+Enter 保存全部可用，切换时内容双向迁移不丢字。编辑器字号 12~22 可调，两模式字号统一，调整即记住。

## 问 AI：批注讨论区

编辑器下方是「问 AI」工具行：以被批注的原文为上下文与 AI 多轮讨论。与 AI 的基础问答免费；**邀请 AI 角色参与讨论、把讨论结论一键压缩成简短笔记并入批注正文为 Pro 功能**（未激活时触发即弹统一解锁框）。AI 未配置时会引导先去设置。

## 查看与删除批注

- **点击原文标记：**弹出气泡直接显示批注内容（同一位置多条批注时可在气泡内切换），气泡提供**编辑 / 问 AI / 删除**三个操作，删除需确认并连带清除原文中的标记。块级批注在文字上无标记——点击块的**左缘色条**打开气泡；
- **批注面板：**侧边栏批注分区按时间列出当前文档全部批注——选区批注显示原文摘录，块级批注带徽标；点击任意条目即滚动定位到原文；
- **显示 ID** 开启后，面板顶部显示光标所在位置的笔记本 / 文档 / 列表 / 超级块 / 引述块 / 当前块 ID（点击复制），便于反馈与排查；
- 面板皮肤（经典 / 糖霜 / 纸墨 / 疏朗）可在设置中更换。

## 批注存在哪里：块属性 + 草稿文档

- 批注保存在**原文块的属性**中：跟随原文块移动、复制与同步，不存在需要单独打理的「批注文件」；
- 富文本模式的编辑过程会使用全局草稿文档 **.tomato-批注草稿**——它只是编辑容器（即用即删、重启自动清扫），默认藏在你所选笔记本最近一篇日记的**上一个月份目录**里以最小干扰，无害、可随时删除；
- 设置项「批注草稿存放笔记本」指定草稿文档的安家笔记本，批注收集「当天日记」去向也用这本：不选则跟随系统日记本。

## 批注标记样式

在设置中定制批注在原文中的视觉形态：

- **标记形态：**下划线式 / 马克笔式 / 花边框；
- **下划线式：**线型七种（实线 / 虚线 / 点线 / 波浪线 / 双线 / 圆点串 / 圆圈串），可开「背景微底色」，粗细三档（细 / 标准 / 粗）；
- **马克笔式：**底色厚度三档。

## 侧边栏（Dock）：虚拟引用与正反链

### 实时虚拟引用：随写随查，无需刷新

在正文中输入或光标停留在某个词（如人物名）上时，侧边栏**实时**显示包含该词的所有虚拟引用内容（来自当前文档或其他文档），无需手动刷新——比思源本体虚拟引用体验更好。特别适合小说创作与知识整理：输入人物名「张三」，侧边栏立即显示所有关于「张三」的背景信息批注或提及。

### 查看全文正链

把面板顶部模式切到「文档」档后，侧边栏收集并展示**当前文档全文的正向链接**，非常适合写作时梳理结构——快速查看正文中涉及的所有人物、地点、物品、概念等关键元素的引用情况；也可按 F9 手动刷新。

### 查看光标处的正链、反链与虚拟引用

光标停留在正文某个位置时，侧边栏分区域显示：

- **虚拟引用：**包含光标处关键词的其他内容；
- **正链：**光标处文本指向的其他块（引用）；
- **反链：**指向光标处文本的其他块。

## 批注收集：一键归档引用卡片流

把一个文档（或其整棵子树）的全部批注一键收集到**当天日记 / 指定文件 / 剪贴板**，产物是可跳回原文的引用卡片流——每条批注正文原样迁移（富文本不丢），紧跟一条指向原文的块引用，点击即可跳回。节标题形如「## 📥 《文档名》批注收集 · 09-02」；递归（含子文档）模式时，每个含批注的子文档一个三级标题分组（根文档同样成组）。

**三个入口：**

- **入口一 · 批注面板「收集」按钮：**打开收集小窗，完整选择范围与去向；
- **入口二 · 右键菜单「收集批注」：**平铺快通道——「收集批注 → 剪贴板 / 收集批注 → 当天日记 / 收集批注 → 收集到文件：《上次文件名》」按上次记忆直接执行，「收集批注」打开收集小窗。与「添加批注」同受设置「添加右键菜单」门控，关闭后右键通道一并隐藏；五个菜单项还可在设置的「右键菜单项」中逐项隐藏；
- **入口三 · 命令面板：**「收集批注」按上次配置直接执行；「收集批注 → 剪贴板 / → 当天日记 / → 收集到文件」三个直发命令按名直发（「→ 收集到文件」无上次记忆时打开收集小窗）。均默认不绑快捷键，可在思源键位设置中自绑。

**范围与去向：**

- 范围：**当前文档**（免费）／**含子文档**递归收集（Pro ¥72，收集小窗中带 VIP 徽标；未激活时选项仍可自由查看，执行递归收集才弹统一解锁框，零试用）；
- 去向：**剪贴板**（同构 markdown，粘回思源自动成活块引用）／**当天日记**（追加到日记正文末尾；落到「批注草稿存放笔记本」所选本，未选时跟随系统日记本）／**指定文件**（笔记本 + 路径级联选择；右键快通道与命令记住上次文件，小窗中每次重新选择；目标被删时提示重选）；
- 执行完成后 toast 回执「已收集 N 条批注 → 去向」。

**同日替换与只读导出物：**

- 同一天对同一文档重复收集时**原位替换**旧收集节（每天一节，跨天追加新节，保留历史轨迹）；
- 收集节视为**只读导出物**——手动修改过的内容会在下次收集时被覆盖；
- 未发现批注 / 未找到日记笔记本时会明确提示，不静默失败。
