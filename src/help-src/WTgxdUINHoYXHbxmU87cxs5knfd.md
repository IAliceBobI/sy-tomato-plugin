引用修复工具用于给笔记中的块引用「加固」：原文被删除或 ID 改变后，引用仍可被修复或「复活」。在插件设置中开启「引用修复工具」总开关（实验功能）后可用，使用前请备份。

这是一个实验功能，请提前备份好。

## 功能简介

针对思源笔记用户普遍遇到的引用丢失痛点（如原文误删、副本存在但引用失效），番茄工具箱提供了一套自动化引用修复与防护体系。通过深度解析思源笔记的块引用机制，实现了对文档级和块级引用的全生命周期管理，尤其适用文档频繁迭代的场景。

它的工作方式是在引用属性上保存原文的快照与特征。此后若原文 ID 改变（原文被删除但保留了副本），可把引用修复并重新指向新原文；若原文被彻底删除，也能凭引用属性上的快照「复活」原文（快照可能只包含部分原文，例如原文是列表时）。

例如：把某个文档整理重写后，旧块被删除、新块由旧内容复制而来，普通引用此时已经失效；经过加固的引用可以修复并重新指向新副本，无需手动逐条重建。对于原文是文档的情况、以及一个块中包含多个指向不同原文的引用，同样适用。

## 快速上手

1. 在插件设置中开启「引用修复工具」总开关（实验功能），并开启「打开或关闭文档时，自动对当前文档中的引用进行加固处理」。
2. 首次使用，先做一次全局加固：右键菜单「全局加固文档引用」，快捷键 Ctrl+Alt+Shift+1（macOS 为 ⌥⇧⌘1）。
3. 遇到引用丢失时，使用右键菜单「全局修复文档引用」（Ctrl+Alt+Shift+2 / ⌥⇧⌘2）修复。
