文档树工具在文档树右键菜单中提供三个批量操作：把选中的多个目录导出为一个 Markdown 文件、把多个目录的内容合并到其中一个目录、从本地导入 Markdown 或文本文件。无独立设置项，安装插件后即可使用。

## 功能简介

思源的内容偶尔需要「整体进出」：想把一批笔记喂给 AI 知识库（如 ima），要一篇篇打开复制；想把本地的 Markdown、文本收进思源，或者把几个零散文档并成一个，都缺少顺手的全量操作。

文档树工具在文档树右键菜单中补齐了这三个动作：把选中的多个目录导出为一个 Markdown 文件（`all.md`）、把多个目录的内容合并到其中一个目录（复制或移动）、从本地路径导入 Markdown 或文本文件。

一个典型用法：选中一个笔记本的顶层目录批量导出成 `all.md`，直接上传到 AI 知识库，省去逐篇搬运。

> **本文把一个文档及其子文档合称为`目录`。**

## 合并：把多个目录的内容合并到其中一个目录

合并方式为复制或移动。

合并的目的地是选中的目录之一，默认为第一个选中的目录。

如果只选中一个文档，相当于把其子文档的内容复制/移动到该文档中。
