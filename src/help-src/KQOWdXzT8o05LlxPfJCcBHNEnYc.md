阅读点用来记住每个文档上次阅读到的位置，设置后可以一键跳回原位继续阅读。在插件设置中开启「阅读点」总开关后即可使用。

## 功能简介

读长文档（教程、源码分析、长篇笔记）时经常读到一半就中断，下次打开已经不记得上次读到哪里。思源自带的书签可以标记位置，但需要手动添加、手动清理，时间久了书签面板里会堆满过期的标记。

阅读点把这个流程自动化：每篇文档永远只有一个"上次读到的地方"，设新的自动清旧的。主交互面是**悬浮球**——平时收缩成一个小球贴在屏幕边缘，几乎不占地方；点击展开成操作条，设点/跳回/删点/最近在读一览无余。

阅读点直接记录在原文块上（不动你的笔记内容、不进闪卡），支持任意块类型；列表按时间倒序排列、可搜索、可单条删除。

## 悬浮球：收缩成球，展开成条

[图片]

开启「阅读点」总开关后，屏幕右侧出现悬浮球（默认中右偏下位置）：

- **收缩态（球）**：书签图标就是当前文档的状态灯——**点亮（主题色）**表示当前文档已有阅读点，**半暗**表示还没有。点击球展开操作条；
- **展开态（条）**：从球向上展开，分两段——
  - 动作区四个按钮：设置阅读点 / 跳回 / 删除 / 打开「最近在读」面板（无阅读点时"跳回/删除"置灰）；
  - 「最近在读」行：最近 5 篇有阅读点的文档（文档名+相对时间），点击直接跳过去续读。
- 再次点击球或点击条外任意位置收起回球态。

球可以**拖拽**到屏幕任意位置（松手自动吸附到最近的边缘锚点）；**右键点击（移动端长按）**打开菜单：设置阅读点 / 跳到当前文档的阅读点 / 删除当前文档的阅读点 / 查看阅读点 / 隐藏悬浮球。

球隐藏后，点击**顶栏书签图标**（默认开启）或状态栏开关钮即可找回；这两个入口同时也是悬浮球的显隐开关。

## 快捷键：F7 / Alt+F5

光标定位到要标记的位置后，按 `F7` 设置阅读点（也可在右键菜单中选择「设置阅读点」），选中的块优先、其次光标块、都没有时取当前屏幕最上方的可见块。之后随时用 `Alt+F5` 跳回当前文档的阅读点，`Ctrl+F7` 删除当前文档的阅读点。

快捷键可以在思源「设置 → 快捷键」中搜索命令名自行修改。

## 最近在读面板：Ctrl+Shift+Enter

[图片]

按 `Ctrl+Shift+Enter`、悬浮球操作条上的「面板」按钮或命令面板中的「查看阅读点」，打开「最近在读」面板：所有文档的阅读点按设置时间倒序排列，每条显示文档路径、原文摘录和相对时间，顶部搜索框可按文档名或摘录过滤，点击条目跳转，条目右侧的垃圾桶按钮单条删除。

旧版本的阅读点（以内容块形式保存）也兼容显示，带「旧版」徽章；在该文档按一次 `F7` 或「删除当前文档的阅读点」即自动迁移/清理为新格式。
