# 番茄工具箱 Tomato Toolbox

思源笔记的全能效率工具箱——一个插件位，装下一整套笔记工作流，全部开源。

## 核心亮点

- 🧰 **全能工具箱**——按场景分区、40+ 项功能：专注、阅读、复习、捕捉、引用、可视化、AI，装一个省一排插件位
- 🍅 **状态栏番茄钟**——点击即开，专注/休息自动轮转，背景图与提示音随你配，最小打扰
- 🤖 **AI 能力**——基于自己笔记的知识库问答，流式输出、答案有出处；批注讨论可沉淀为内容块
- 📖 **阅读输入闭环**——阅读点记住读到哪，批注随手划，读过的内容一键制成复习卡
- 🃏 **闪卡复习增强**——优先级排序、图片挖空、复习中顺手删卡、失效卡一键清理

## 功能总览

### 🍅 专注与时间

- **状态栏番茄钟**——点击即开，专注/休息自动轮转；时长、背景图、提示音（木鱼/铃声/自定义上传）随你配
- **定期提醒**——周而复始的事，到点自动提醒

### 📖 阅读与批注

- **阅读点**——标记读到哪了，下次接着读；悬浮球一键跳转，还能把读过的内容制成复习卡
- **批注**——下划线/马克笔/花边框三种标记形态，四种面板皮肤；批注下的 AI 讨论可沉淀为内容块

### 🃏 闪卡与复习

- **闪卡优先级**——重要的卡先复习，连对连错自动调级
- **图片挖空**——图片局部遮挡制卡
- **复习中删卡**——复习界面顺手删掉废卡
- **失效卡清理**——一键清理失效闪卡

### ⚡ 捕捉与速记

- **拍照闪念**——手机拍照秒存闪念
- **快速笔记**——外部小窗随手记，草稿自动保存
- **移到今日笔记**——任意块一键挪进今天的日记，划词即可复制片段

### 🔗 引用与同步

- **同步块**——一处修改，处处同步
- **双向互链**——两个块互相引用，A 面 B 面一键跳转
- **文本转引用**——选中文字原地变引用块
- **底部反链**——编辑器底部常驻反链面板
- **数据库反链**——数据库视图里的反链

### 🧭 可视化

- **思维导线**——大纲一键展开成思维导线，划词连线
- **块关系图**——块之间引用关系的可视化
- **块编辑器**——把任意块放进独立编辑器专注处理

### 🗂 文档整理与导出

- **导出工作空间**——整个工作区导出为 Markdown，白名单/黑名单可控，支持自动增量
- **文档合并**——多个文档一键并成一个
- **DailyNote 工具**——上一份/下一份日记导航、回顾日记、批量移动内容

### 🤖 AI

- **AI 知识库问答**——基于自己的笔记问答，流式输出，答案有出处

> 还有编辑器小工具一排：折叠增强、多行选择、列表工具、复制为图片、文档别名……装好就在右键菜单里，不占一个插件位。

## 上手

1. 安装后看思源状态栏——点击番茄图标，开跑第一个番茄钟
2. 打开插件设置（思源设置 → 插件 → 番茄工具箱），按习惯逐域调整
3. 其余功能不用背：命令面板搜「番茄」全部列出，或到帮助文档按场景找
